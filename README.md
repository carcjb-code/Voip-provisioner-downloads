## Actualizaciones y advertencias

- La descarga inicial de los APK es pública.
- En estas compilaciones Android, el actualizador incremental de Mantenimiento todavía depende del repositorio privado. Hasta publicar una versión del actualizador preparada para distribución pública, esa función puede no estar disponible para usuarios externos.
- Los ZIP de Windows contienen la aplicación portable. Extraer el contenido antes de ejecutarla.

No utilizar compilaciones de prueba en centrales de producción sin validarlas primero en un entorno de laboratorio. Antes de reinstalar o cambiar una versión, exportar los perfiles de servidor y comprobar que puedan restaurarse.

MANUAL DE USO

VoIP Provisioner permite administrar teléfonos y extensiones de un servidor Issabel desde la aplicación. Para operar sobre Issabel primero necesitás configurar y seleccionar el servidor.

1. Configurar el servidor

Entrá en Configuraciones y abrí Servidores SSH. Cargá host, usuario y clave, guardá el perfil y comprobá la conexión. Seleccioná el perfil correcto antes de sincronizar o hacer cambios.

2. Provisionamiento

Sincronizá la información existente antes de modificar extensiones. Revisá interno, edificio, piso, dependencia, modelo y MAC. Comprobá los datos para evitar reemplazar una configuración válida.

3. Monitoreo

Consultá el estado de internos, troncales y llamadas. Antes de colgar una llamada o cambiar una regla, verificá que estás trabajando sobre el servidor correcto.

4. Excel y planillas

Verificá el perfil seleccionado, la ruta y los permisos del archivo maestro. Comprobá el resultado de cada descarga o actualización.

5. Plantillas de teléfonos

Elegí una plantilla que corresponda exactamente al modelo del equipo. No uses plantillas de otro fabricante o modelo. Comprobá que las modificaciones queden guardadas.

PREGUNTAS FRECUENTES

No conecta con Issabel

Revisá IP, conectividad, puerto SSH, usuario, contraseña y permisos.

Figura online, pero la sincronización falla

Que el servidor responda no garantiza que el usuario SSH tenga permisos para todas las operaciones. Revisá el mensaje de error y los permisos.

No puedo crear o modificar un interno

Confirmá que elegiste el perfil correcto, sincronizá primero y revisá interno y tecnología.

No aparecen los cambios de una plantilla

Volvé a abrir la sección y confirmá si se guardaron. No cierres la aplicación mientras una operación indique que está en curso.

RECOMENDACIONES

Usá primero un servidor de prueba. Antes de modificar dialplan, rutas o configuraciones del PBX, asegurate de contar con una copia de seguridad. Si una operación falla, guardá el texto exacto del error.
